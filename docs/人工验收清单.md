# StudyGraph 人工验收清单

> 对应版本：**0.25.1**
> 编写日期：2026-11-23
> 配套文档：[使用说明书.md](使用说明书.md)（同一份功能说明，这里只列"怎么验"）

自动化测试（`npm run test:unit` / `test:integration`）已经覆盖了数据层、模型路由、作用域隔离、JSON 解析这些能写成断言的部分。
**这份清单只收自动化测不到的东西**：装起来的样子、鼠标的手感、AI 真的改没改画布、卸载后数据还在不在。

---

## 怎么用这份清单

| 记号 | 含义 |
| --- | --- |
| **P0** | 不通过就不能发版（装不上、数据丢、主链路断） |
| **P1** | 重要功能坏了要先修 |
| **P2** | 边角情况，可以带着问题发版 |
| 🤖 | 已有自动化覆盖，这里只做冒烟（跑一遍看没变样） |
| 👁️ | **必须人看**：视觉、拖拽手感、弹窗措辞、实际调用的是哪个模型 |

**记录格式**（建议每轮新建一个表）：

```
版本 | 机器 | 结论 | 不通过项编号 | 现象/截图
0.25.1 | Win11 22H2 | 待验 | — | （0.25.0 遗留的两项已修）
```

**每次都要从干净状态开始**：卸载（选"删除数据"）→ 确认 `%LOCALAPPDATA%\StudyGraph` 不存在 → 重新安装。

## 16. 建议的测试顺序（省时间）

一轮完整验收大约 2.5 小时，按这个顺序做最不容易返工：

1. **装 + 启动**（第 1 节，20 分钟）——装不上后面的都做不了
2. **配置密钥 + 拉模型**（12.1–12.5，15 分钟）
3. **主链路跑通一份真实课件**（第 5、6 节，40 分钟）——这是产品的核心价值
4. **画布交互手感**（第 2、3、4、7 节，35 分钟）——纯人工，只能现场看
5. **AI agent 与出题质量**（第 8、9、10 节，35 分钟）——最需要人的判断
6. **复习 / 题库 / 错题**（第 11 节，10 分钟）
7. **卸载重装往返**（第 13 节，20 分钟）——放最后做，因为它会清空数据
8. **回归专项**（第 15 节，15 分钟）
