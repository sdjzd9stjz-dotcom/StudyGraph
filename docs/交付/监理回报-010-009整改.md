**如何解释 3/16。** 存量合格卡为“定义区间”“狄利克雷函数”“连续函数”。13 张待核验包括标题、自述与原文不逐字相等、名称与证据无法按当前规则对齐等情形。降级保留了卡片内容。这一统计仅覆盖 009 的 ch3-2 验收画布，不能据此推断十份课件最多只能产三张卡。语义等价的改写也可能进入待核验；逐字与句式检查不能取代独立的人工语义抽查。

**缓存配置。** 部署固定快照或确认别名对应版本后，可配置 `STUDYGRAPH_EXTRACT_MODEL_VERSION`。执行前的版本预期须与上次实际响应一致才可能命中；别名与实际版本不一致且未配置时会重新调用。配置是部署方对版本的声明，供应商在同一别名下静默换版时，离线缓存不能自行探知，应同步更新配置。旧 Run 保留原字段，新 Run 写入实际信息。
