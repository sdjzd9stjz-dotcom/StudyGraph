## 3. 这一版解决的两个「能不能用」问题

### 3.1 空库没有身份 → 所有接口 401

接口一律要求 `Authorization: Bearer sg_pat_...`。内置库是空的，没有用户也没有 token。
开发期是靠仓库 `.env` 里的 dev token 顶着的，学生机器上没有那个文件。

现在首次启动自动建：一个本机用户 + 全 scope 的 PAT，明文落 `local-token.json`（0600），
库里只存 sha256，明文通过进程环境变量 `STUDYGRAPH_DEV_PAT` 传给 Web。
**幂等**：token 还在且未吊销就复用，不会每次启动都新签一枚。

同时修掉了 Web 端一处构建期内联：`CreateCanvasButton` 原来读 `NEXT_PUBLIC_DEV_PAT`，
那个前缀在构建时就被写死进 bundle，桌面版每次启动才拿到 token，运行时给环境变量对它无效——
点「新建画布」永远 401。改成与 `CanvasEditor` 一致的做法：服务端读，作为 prop 传给客户端组件。

### 3.2 课件没地方存 → `ObjectStore` 加 `local` 实现

桌面版没有 S3。新增 `kind: 'local'`：本机目录即桶，根目录由 `STUDYGRAPH_OBJECT_DIR` 指定
（桌面版自动注入 `<数据目录>/objects`）。语义与 S3 对齐：put 覆盖、get 不存在即报错、
deleteMany 幂等。

key 的每一段只允许 `[A-Za-z0-9._-]`，非法直接报错，**不做「替换成下划线」**——
那会让两个不同 key 落成同一个文件，而且完全静默。

实测：

```
kind = local
put 后文件存在： true
get 内容： [ 1, 2, 3 ]
覆盖后： [ 9 ]
取不存在的对象报错： 对象不存在：canvas/c1/source/nope/original.pdf
✅ 拦截非法 key： ../etc/passwd
✅ 拦截非法 key： canvas/../../x
✅ 拦截非法 key： canvas/c1/a b
删除（同一 key 两次，验幂等）： { deleted: 2, orphanKeys: [] }
什么都没配时 kind = none
```

## 3.3 主链打通：上传课件 → 执行（2026-11-20 补）

之前后端能跑执行，但界面上既不能传课件、也没有执行按钮 —— 产品主线是断的。现在：

- `POST /v1/canvases/:id/sources`：裸字节上传（不引新依赖），文件名走 `x-filename`（URI 编码，
  避免中文文件名在头部被按 latin1 截断）。先写对象存储、成功后才建节点 ——
  反过来的话节点会指向不存在的文件，执行时才炸。
- 画布页加了「上传课件」和每个节点的「执行」按钮。执行必须由用户点，
  对应硬约束「执行必须显式触发」。

实测（真实课件 `ch3-1（1）.pptx`，225808 字节）：

```
上传: 201 {"node":{"type":"SOURCE","status":"DRAFT","title":"ch3-1（1）.pptx"...}}
执行: 200 {"status":"SUCCEEDED","cacheHit":false,"fingerprint":"6a4d7a3b..."}
库内: PPTX|ch3-1（1）.pptx|9 页|225808 字节|checksum 有
Span: 9 条
节点状态: SOURCE|READY
```

## 3.4 多供应商与 BYOK（0.2.0，2026-11-20）

规格要求供应商是**数据**而不是代码里的联合类型：校园网关、企业代理、本地 Ollama、
各家 OpenAI 兼容端点，写死两三家覆盖不了。

### 数据模型（4 张表，migration `20261121000000_multi_provider`）

| 表 | 作用 |
| --- | --- |
| `Provider` | 供应商目录。预置 10 家（`isCustom=false`），学生自建端点 `isCustom=true` + `ownerId` |
| `ProviderModel` | 模型清单：上下文、能力声明、单价 |
| `UserCredential` | 用户密钥（AES-256-GCM 密文 + last4 + 状态 + `baseUrlOverride`） |
| `UserModelPref` | 按 taskType 的模型偏好 |

预置 10 家：OpenAI、DeepSeek、Anthropic、Google Gemini、Moonshot/Kimi、智谱 GLM、
阿里通义 DashScope、硅基流动、OpenRouter、Ollama（本地，key 可为空）。

### 拉取模型列表 + 按任务选模型（0.11.0）

预置目录里的模型名会过时（厂商加新模型、下架旧模型），学生也不该翻文档抄模型名。
现在每个供应商卡片上有一个「拉取模型列表」按钮：用**你自己保存的密钥**去问厂商
「你有哪些模型」，拉回来落库并展示成标签，点标签可启用/停用。

协议差异只体现在 URL 与鉴权头上，不复制多份适配器：

| 协议 | 端点 | 鉴权 |
| --- | --- | --- |
| OPENAI | `GET {baseUrl}/models` | `Authorization: Bearer` |
| ANTHROPIC | `GET {baseUrl}/v1/models` | `x-api-key` + `anthropic-version` |
| GEMINI | `GET {baseUrl}/v1beta/models?key=` | query 参数 |

下方新增「各任务用哪个模型」：切片 / 抽取 / 判题 / 出题 / 三检 / 变式 / 题型识别 /
解法抽取 / 分步解法，每项一个下拉框，选项是「所有已存密钥的供应商 × 已启用模型」。
不选就走 `routing.ts` 的默认路由。

实测：

```
未存密钥时拉取: 400 PROVIDER_CREDENTIAL_MISSING
存假密钥: 201
用假密钥拉取: 502 | 拉取模型列表失败（401）：Authentication Fails, Your api key: ****test is invalid
拉取按钮数量: 10
任务偏好区: true
偏好下拉数量: 9
```

第二条是关键：**上游返回了 401**，说明请求真的发到了 DeepSeek，而不是被本地逻辑拦下。

### 关键改动：网关按协议分派

之前网关按固定三家硬分派，自定义端点根本进不来。现在凭据解析返回**完整调用目标**
（协议 + baseUrl + 模型），网关按 `protocol` 选适配器。
`ProviderId` 从字面量联合类型改成开放字符串 —— 供应商来自数据表，不可能穷举。

### 实测（真机，0.2.0）

```
加密就绪: true | 预置供应商: 10
名单: openai, deepseek, anthropic, gemini, moonshot, zhipu, dashscope, siliconflow, openrouter, ollama
预置项存 key: 201 只回 last4: wxyz | 泄漏明文: false
自定义供应商: 201 custom-22c39bff | 模型: [ 'qwen-max' ]
自定义端点 key: 9999
任务偏好: 201
能力不匹配被拒（期望 400）: 400 MODEL_CAPABILITY_MISMATCH
  该任务需要 jsonObject 能力，而 Claude Sonnet 4.5 未声明支持
全量响应含任何明文: false
```

最后一条是规格「三个产品问题②」的落地：学生为省钱选了不支持 JSON 输出的模型跑
`extract`，整条链路产物会作废而他不知道为什么 —— 所以**保存即拒绝**，并说明缺哪项能力。
厂商没声明能力时允许选（打 UNTESTED），不瞎填 `true`。

## 4. 安装包本身的约束

- **安装路径必须纯 ASCII**。Electron 与 PostgreSQL 的二进制在含中文的目录下都会失败，
  而且报错毫不相干（Electron 直接退出码 3；PG 说 `Permission denied`）。
  安装器在选目录页会拦住非 ASCII 路径并说明原因。
- 卸载时会问「是否一并删除数据」，选否则保留，方便重装后接着用。

## 6. 怎么重新打

```bash
# 1. 准备 PostgreSQL 运行时（仅在官方二进制/pgvector 更新时需要重跑）
node scripts/prepare-pg-runtime.mjs

# 2. 打包成目录形态
node scripts/build-desktop.mjs

# 3. 打安装包
MSYS2_ARG_CONV_EXCL='*' "C:\Users\<you>\AppData\Local\Programs\Inno Setup 6\ISCC.exe" \
  "/DSourceDir=<仓库>\dist-desktop\<时间戳>\StudyGraph" "/DAppVersion=0.1.0" \
  scripts/desktop-installer.iss
```

> Git Bash 下必须加 `MSYS2_ARG_CONV_EXCL='*'`，否则 `/VERYSILENT`、`/D...` 这类参数
> 会被当成路径转换掉，表现为「You may not specify more than one script filename」。
