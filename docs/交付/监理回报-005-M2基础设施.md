## 4 无源拦截

**未做**（依赖 `card`）。

但"span 校验"这一层已经落地并有断言——它正是无源拦截的执行点：

```
✔ text 与页文本逐字符相等 → 通过
✔ text 与原文不符 → TEXT_MISMATCH（造假检测在这里）
✔ charStart == charEnd → BAD_RANGE
✔ charEnd 超出页长度 → BAD_RANGE
✔ 页码不存在 → PAGE_MISSING
✔ 只有空白的 span → EMPTY_TEXT
✔ resolver 缓存：同一 span 第二次不重复取页文本
```

两条 SQL（预期 0 / 空）等有卡之后再跑，现在库里本来就没有 Concept。

## 5 指纹

### promptVersion 的计算方式（不是手写常量）

`packages/contracts/src/fingerprint.ts`：

```ts
export function promptVersionOf(promptText: string): string {
  return sha256Hex(promptText).slice(0, 12)
}
export function computeFingerprint(input: FingerprintInput): string {
  const payload = [
    canonicalJson([...input.upstreamArtifactHashes].sort()),
    canonicalJson(input.params ?? {}),
    input.modelVersion,
    input.promptVersion,
  ].join('\u0000')
  return sha256Hex(payload)
}
```

`modelVersion` 由 Gateway 取**厂商响应里的 model 字段**（单测已断言：拿到的是
`gpt-4o-mini-2024-07-18` 而不是别名 `gpt-4o-mini`）。

### 单测覆盖（10 条）

```
✔ 同一输入两次 → 同一指纹
✔ 上游 artifacts 变 → 指纹变
✔ params 变 → 指纹变
✔ modelVersion 变 → 指纹变
✔ promptVersion 变 → 指纹变
✔ 上游 hash 顺序不同但集合相同 → 同一指纹
✔ canonicalJson：键序不同、内容相同 → 同一字符串
✔ canonicalJson：数组顺序不许排序
✔ canonicalJson：丢弃 undefined、保留 null
✔ promptVersionOf 由 prompt 文本决定，12 位十六进制（改一个句号就不同）
```

行为层（二次运行 tokensIn=0 等）**无法验证**：没有 executor 就没有 Run 记录。
