# StudyGraph 桌面客户端 0.14.0 · 交付与实机验收

> 2026-11-21。回答一个问题：**这个包拿到别的电脑上，不装任何东西，能不能直接装、直接跑起来。**

结论：能。下面是可复现的证据，以及两处必须知道的前提。

## 2. 包内自带什么（逐项核对，不是"应该带"）

| 依赖 | 是否自带 | 证据 |
| --- | --- | --- |
| Node.js 运行时 | 自带 | 用 Electron 自带的 Node 跑服务端：`spawn(process.execPath, …, { ELECTRON_RUN_AS_NODE: '1' })`。机器上不需要装 Node |
| PostgreSQL 16.9 | 自带 | `resources/pgsql/bin/postgres.exe`，EDB 官方 Windows x64 二进制，裁剪后 66 MB |
| pgvector 0.8.0 | 自带 | `resources/pgsql/lib/vector.dll` + `share/extension/vector.control`（自编译） |
| VC++ 运行库 | 自带 | `resources/pgsql/bin/vcruntime140.dll`、`msvcp140.dll`。`postgres.exe` 只导入 `vcruntime140.dll`，**不**依赖 `vcruntime140_1.dll`（已用二进制串扫描确认，故未提供该文件也不缺） |
| 数据库驱动 | 自带 | `node_modules/.prisma/client/query_engine-windows.dll.node`（Prisma 原生引擎） |
| 对象存储 | 不需要服务 | 桌面版 `kind: 'local'`，`<数据目录>/objects` 就是桶 |
| Redis / BullMQ | 不需要 | `REDIS_URL` 是 optional；执行链路是同步的，没有队列 |
| Docker | 不需要 | 无任何容器依赖 |
| 网络 | 不需要（首启动） | 建库、迁移、签发 token 全在本机完成。只有调模型才联网 |

`node_modules` 里的运行时依赖已逐项核对齐全：`fastify`、`zod`、`@prisma/client`、`@aws-sdk/client-s3`、`unpdf`、Next 的 standalone 依赖（`next`/`react`/`react-dom` 等 15 个）。

架构限制：**x64 Windows**（`ArchitecturesAllowed=x64compatible`）。

## 4. 中文用户名 / 中文路径

PostgreSQL 二进制在含中文的路径下会失败（`initdb: Permission denied`；
数据目录在中文路径下报 `invalid byte sequence for encoding "UTF8": 0xb8`。
同一份二进制在 `C:\tmp` 下 sha256 相同却可以跑，故判定为路径编码问题）。

因此数据目录按候选链自动回退：`%LOCALAPPDATA%` → `%ProgramData%` → 系统盘根。

实测（把 `LOCALAPPDATA` 指向含中文的路径模拟中文用户名）：

```
[studygraph-desktop] 跳过非 ASCII 路径：C:\tmp\张三的电脑\LocalAppData\StudyGraph
[studygraph-desktop] 内置库已初始化： C:\ProgramData\StudyGraph\pgdata
[studygraph-desktop] 数据库模式：embedded
[api] ... unionSize:17
```

回退目录的写权限也实测过：标准用户（非管理员）对 `C:\ProgramData\StudyGraph`
与 `C:\StudyGraph` 均可创建并写入。

安装目录本身含中文时，运行时会释放到 ASCII 数据目录（`ensureRuntimeDir`），
不必把软件装在英文路径。

## 5. 已知限制（都是实测出来的，不是推测）

1. **安装包不要在项目目录里双击运行。**
   从 `D:\ai学习辅助工作流搭建\dist-desktop\installer\` 直接启动 Setup 会立刻退出，
   退出码 1，**不写日志、不报错**。同一份 exe 拷到 `C:\tmp`、`D:\sgtest`、
   `D:\测试目录`、`C:\tmp\中文测试` 再运行，退出码均为 0 且安装成功。
   所以这与中文路径无关，是本机对该目录的策略问题。
   **交付给学生时把 exe 单独拷出来再运行**（正常下载场景本来就是如此）。

2. **升级安装会保留旧数据，但旧版本进程必须先退出。**
   安装器会把文件覆盖到 `%LOCALAPPDATA%\Programs\StudyGraph`。
   如果旧版 StudyGraph 还在运行，文件被占用，覆盖会失败。

3. 卸载时询问是否连带删除数据目录；选"保留"则 `byok-key.json` 也在，
   下次装回来厂商密钥仍可解开。

## 6. 与上一版（0.13.0）的差异

- 补齐 `QUIZ` / `GRADE` / `REVIEW` / `GATE` 四个执行器，17 个 NodeType 全部可运行
- `QUIZ` 真正写入 `Problem` 表（此前题库、组卷、作答、错因看板四条链**没有数据源**）
- `GRADE` 真正写入 `Attempt` 表，确定性判分不调模型
- 新增 `POST /v1/nodes/:id/gate-decision`：闸门放行/拒绝留痕，拒绝必填理由
- 画布上 GATE 节点显示闸门条（已放行 / 待确认 + 放行/拒绝按钮）
- 修复 `attempts.ts` 未 select `options` 导致错因标记永远静默失效
