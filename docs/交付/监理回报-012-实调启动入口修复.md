# 012 工程交付 · Windows 实调启动入口

用户终端拒绝执行未签名的 011 PowerShell 脚本。工程 AI 新增 [Node 启动入口](../../scripts/start-011-deepseek.mjs)，可在任意工作目录启动原有的 011 实调程序。该入口使用隐藏输入、禁用输入历史，保留已有账本检查与原程序的预算限制。

在本机 PowerShell 中执行：

```powershell
node "D:\ai学习辅助工作流搭建\scripts\start-011-deepseek.mjs"
```

在提示中粘贴轮换后的密钥并按回车。空输入或 Ctrl+C 可取消。

工程自测在项目目录外执行上述命令并附加 `--preflight`，退出码 0，输出如下：

```text
Authorized files verified: 10
Remaining input/output tokens: 57162 19214
```

实际终端测试中出现隐藏提示，空输入回车后输出“已取消，未发起请求。”并以 0 退出。本轮修复未发起新的付费调用；010 的十份课件实调仍以 011 账本为准。
