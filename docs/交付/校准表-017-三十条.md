## 规格摩擦（需要记住的一条）

`#9`（sim=1.000）与 `#28`（sim=1.000）都没有判成 `VERIFIED`，因为 T1 要求的是 **`definition === quote` 逐字相同**，而不是「相似度 1.0」。

这是 2026-11-20 用户拍板「选 A」的直接后果：**T1 保持严格，`VERIFIED` 长期为 0 是预期行为**，数量口径改由人工复核产生。要拿到 `VERIFIED ≥ 10`，路径是人工把这批 `PENDING_REVIEW` 审上去，而不是松判据。

## 双负例（阈值有效性的证明）

只贴正例证明不了阈值在工作，所以三条负例必须同时给出：

```

NEG2 引文在本页但定义无关 => UNVERIFIED NAME_NOT_IN_DEFINITION sim=0.000
```
