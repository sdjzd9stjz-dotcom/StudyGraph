## 1. 它是什么，能帮你做什么

StudyGraph 是一个**把学习流程画成图**的工具。你把课件丢进去，它按你摆的节点顺序一步步处理，最后产出：

- **可溯源的知识卡** —— 每张卡都能点回原文那一页、那一句
- **复习计划** —— 按你实际的记忆强度安排，不是固定第 1/3/7 天
- **练习题** —— 每道错选项都绑定一种具体的思维错误，选错了能告诉你错在哪一类
- **错因统计** —— 你常犯的是"概念没懂"还是"算错"

和普通笔记软件的区别：**过程是可见的**。哪个节点用哪个模型、读了哪些原文、产出了什么，都留在画布上，你能看、能改、能重跑。

### 两个必须先理解的概念

**节点不会自己跑。** 你把节点摆上画布，它们只是"待办"。每个节点都要你自己点 ▶ 运行。这是刻意的设计 —— 一批节点跑一次可能花掉几毛到几块钱的模型费，自动跑等于替你的钱包做决定。

**上游变了，下游会变灰（STALE）。** 但**不会自动重跑**。你需要自己判断要不要重跑下游。

## 2. 安装与第一次打开

### 装

双击 `StudyGraph-Setup-0.21.6.exe`。

- **不需要管理员权限**，装在你自己的用户目录下
- **不需要装 Node、Python、数据库、Docker** —— 全部自带
- 装完在开始菜单里找 `StudyGraph`

> ⚠️ 如果安装器双击后**什么都没发生**（没有窗口、没有报错），说明这个 exe 所在目录被系统策略挡住了。
> 把它复制到桌面或「下载」文件夹再双击即可。

### 第一次打开会慢十几秒

第一次启动要初始化内置数据库（建库、建表、建索引）。进度在软件自己的日志窗口里，看到 `Web 就绪` 就打开了。之后启动是秒开。

### 你的数据存在哪

```
C:\Users\<你>\AppData\Local\StudyGraph\
  pgdata\             数据库（所有画布、卡片、做题记录都在这）
  objects\            上传的课件原文件
  local-token.json    本机身份令牌
  pg-credentials.json 数据库密码（随机生成）
  byok-key.json       模型密钥的加密主密钥
```

如果你电脑的 Windows 用户名是**中文**，数据库会自动改放到 `C:\ProgramData\StudyGraph\`（中文路径下 PostgreSQL 起不来）。软件会自己在日志里写明用了哪个目录。

**备份 = 复制整个 `StudyGraph` 文件夹。**

## 3. 界面导览

### 首页

| 位置 | 作用 |
| --- | --- |
| 新建画布 | 建一张新的画布 |
| 今日到期 N | 今天该复习的卡数，点进去开始复习 |
| 题库 | 看这张画布出的题、勾选组卷 |
| 错题看板 | 错因分布统计 |
| 模型供应商 | 配 API 密钥、选模型 |

### 画布页

分三块：

```
┌──────────────────────────────────────────────────┐
│ 顶栏：← 全部画布   N 个节点   上传课件  模型供应商  今日到期 │
├──────────┬───────────────────────────────────────┤
│ 左侧栏    │                                       │
│          │              画布                      │
│ 技能      │        （节点摆在这里）                 │
│ 常用节点 6 │                                       │
│ 高级节点 11│                                       │
├──────────┴───────────────────────────────────────┤
│ 底部 AI 对话栏：告诉 AI 你想做什么…          [发送] │
└──────────────────────────────────────────────────┘
```

**左边栏 = 你可以用的东西**，把它们拖进画布就是这个意思。

**每个节点长这样：**

```
┌──────────────────────────────┐
│ 概念抽取  READY  💬  ▶   ✕   │ ← 类型 · 状态 · 对话 · 运行 · 删除
├──────────────────────────────┤
│ （鼠标移上来才展开的提示词窗） │ ← 悬停显示，可改提示词和参数
├──────────────────────────────┤
│ 📄 卡片：跑完之后的产出解释    │ ← 常驻，可滚动
│ • 导数的定义：……             │
└──────────────────────────────┘
```

**跑完之后节点上会出现一张"解释卡片"**：不是一行摘要，而是把产物摊开写清楚 ——
课件在哪几页、切了多少段、抽了哪些概念、每道题的题干、组卷的缺口……
整张画布看起来就是一张带内容的知识地图，而不是一堆只有名字的方块。

> 卡片内容是**确定性生成的**（直接从产物里取），不是模型现编的摘要，
> 所以它和节点实际产出一一对应，不会多出没发生过的结论。

**节点状态含义：**

| 状态 | 意思 |
| --- | --- |
| `DRAFT` | 刚建的，还没跑过 |
| `READY` | 跑成功了 |
| `RUNNING` | 正在跑 |
| `STALE` | 上游改过了，这个节点可能过期了 |
| `ERROR` | 跑失败了，鼠标移上去看原因 |

## 4. 十五分钟做出第一条知识链

假设你有一份《高等数学》第 3 章 PPTX。

### 步骤 1：上传课件

画布右上角点 **上传课件**，选 `.pptx`、`.ppt` 或 `.pdf`。

画布上会出现一个 **课件** 节点。这一步只是把文件存进来并抽出文字，还没有动用模型。

跑它（点 ▶）。产物是这一页页的原文。

**扫描件怎么办：** 如果这份 PDF 是拍/扫出来的图片（选中文字选不中），上传前**勾上「扫描件（OCR）」**再上传。
软件会用本机 OCR 识别文字，不需要联网。

两点要有心理准备：

- **慢**：每页约 1–3 秒，60 页的扫描件要一两分钟。
- **会认错字**：OCR 是"把像素猜成字"。公式、手写、模糊的扫描件识别质量明显下降（实测把"微分"认成"做分"）。
  识别结果在产物里标成 `textLayer: OCR`，提醒你这些字不是原文。

没勾 OCR 就上传扫描件，会明确报「没有文字层」并让你重传 —— 不会偷偷帮你猜。

**旧版 `.ppt`（Office 97–2003）也支持**，会自动识别。如果它其实是 `.pptx` 改名而来，会提示你改回 `.pptx`。

### 步骤 2：切片

从左侧栏把 **切片** 拖进画布，把 **课件** 右边的小圆点拖到 **切片** 左边的小圆点，连起来。

跑 **切片**。产物是一段段按页切好的文本。

### 步骤 3：抽概念

拖入 **概念**，从 **切片** 连过来，跑它。

这一步开始用模型了。它从原文里抽出"这个概念叫什么、定义是什么、依据是原文哪一段"。

⚠️ **第一次跑之前先去配好密钥**（见第 12 节）。没配的话这一步会失败并提示你。

### 步骤 4：建知识卡

拖入 **知识卡**，从 **概念** 连过来，跑它。

每一条概念变成一张卡片。**卡片默认状态是"待复核"（PENDING_REVIEW）**，不是直接可用 —— 模型抽的概念可能有偏差，需要你过一眼。

到 **知识卡** 的产物里逐张看，确认无误的点通过（ACCEPT）。**只有通过复核的卡才会出现在复习和出题里。**

### 步骤 5：排复习

拖入 **复习**，跑它。它会列出一份计划：哪些卡今天该看、逾期几天、现在还能记住几成。

点顶栏的 **今日到期** 进去开始背。

### 到此为止

你已经有一条能用的链：**课件 → 切片 → 概念 → 知识卡 → 复习**。

再往下就是做题：

```
知识卡 → 出题(QUIZ) → 质量闸门(CHECK) → 题库 → 组卷(PAPER)
```

**注意**：出题产生的题目状态是 `PENDING`。要经过 **质量闸门** 三检（能不能解、答案对不对、干扰项有没有诊断价值），或者你手工确认，才会变成 `VERIFIED`。**只有 VERIFIED 的题能进卷子。**

## 5. 鼠标操作速查

| 操作 | 结果 |
| --- | --- |
| **拖左侧栏节点到画布** | 新建一个该类型节点 |
| **从端口拖到空白处** | 弹出节点搜索，选中的类型会自动连好线 |
| **从端口拖到另一个节点** | 连线 |
| **拖线时经过节点** | 能接的亮绿边框，接不上的变暗；端口逐个标绿/灰，告诉你"是这根口不行" |
| **鼠标停在端口上** | 提示这个端口能接哪些类型 |
| **双击画布空白处** | 打开节点搜索（打字过滤） |
| **右键画布空白处** | 新建节点（鼠标悬停展开类型菜单）、粘贴 |
| **右键节点** | 运行此节点 / 重命名 / 复制节点 / 打包为上下文 / 删除 |
| **鼠标移到节点上** | 展开提示词窗（可改提示词和这个节点的参数） |
| **拖左侧栏的「技能」到节点上** | 给这个节点绑定技能（见下） |

### 改提示词 / 改参数

鼠标移到节点上，展开的那一栏里就是编辑区：

```
提示词（你希望它怎么做）  [                              ]
节点参数                  [  这个节点专用的字段          ]
                          [ 保存参数 ]
```

1. 在 **提示词** 里写你的要求，例如「只考计算题，不要考概念记忆」
2. 有专用参数的节点（题型识别、变式等）在下面把题目原文填进去
3. 点 **保存参数**
4. **点节点上的 ▶ 重新运行一次** —— 保存只写库，不会替你执行

提示词是**附加要求**，会拼在硬约束之后。你推不翻「没有原文引用不得成为已确认知识」这类规则，但可以决定它怎么出题、从什么角度讲。

### 技能（skill）是什么

技能是一段附加在提示词里的规则。现在内置两个：

- **严格溯源** —— 要求每条结论都必须能指出原文出处
- **中文数学表述** —— 统一用中文数学写法

把技能拖到节点上就绑定了。**绑定会改变这个节点的指纹，所以下次运行一定会重跑**，不会命中缓存 —— 这是对的，规则变了结果就该变。

## 6. 节点速查表

### 常用（左侧栏直接显示）

| 节点 | 做什么 | 需要你填什么 |
| --- | --- | --- |
| **课件** SOURCE | 读 PPTX/PDF 并抽出文字 | 用「上传课件」按钮即可，不用手填 |
| **切片** CHUNK | 把长文按语义切开 | 可选：每片目标字数 |
| **概念** EXTRACT | 从原文抽知识点（名称/定义/出处） | 可选：每批送几段、每段最多抽几条 |
| **知识卡** CARD | 每条概念生成一张可溯源的卡 | 不用填，读画布上待复核的概念 |
| **先修** PREREQ | 推断概念之间的先后依赖 | 不用填，读画布上已确认的概念 |
| **复习** REVIEW | 按 FSRS 排复习计划 | 可选：一次排几张、要不要带新卡 |
| **深入理解** DEEPEN | 从知识卡与题目里提炼核心观点（每条带依据） | 不用填；只吃知识卡和题目的连线 |
| **导出讲义** LECTURE | 把多个节点的产出与对话汇总成讲义，可导出 PDF | 可选：讲义标题 |

### 高级（点左侧栏「高级节点 (11)」展开）

| 节点 | 做什么 | 需要你填什么 |
| --- | --- | --- |
| **出题** QUIZ | 从已确认概念出练习题，**并写进题库** | 题数、可选限定题型/难度 |
| **判分** GRADE | 批量批改作答 | 作答列表 `[{problemId, answer}]` |
| **人工闸门** GATE | 停下等你看一眼再继续 | 在节点上点「放行」或「拒绝」 |
| **题型识别** PROBE | 判断一道题考什么 | 题目原文 |
| **解法抽取** METHOD | 把例题提炼成方法 | 例题原文 |
| **分步解法** SOLVE | 生成带理由的解题步骤链 | 题目原文 |
| **错因归因** DIAGNOSE | 分析你的答案为什么错 | 你的作答原文（可选：题目、正确步骤） |
| **变式** VARIANT | 沿六个维度出变式题 | 原题题干、要几个 |
| **干扰项** DISTRACTOR | 生成有诊断性的错误选项 | 题干、正确答案 |
| **质量闸门** CHECK | 出题后三检 | 题干、答案、选项 |
| **组卷** PAPER | 按规则从题库拼一张卷 | 可选：时长、题型、难度分布 |

### 几个必须知道的规则

**只有"已确认"的概念能出题。** 待复核的卡不算数 —— 拿没确认的知识点出卷子给学生做，是本末倒置。

**题目必须带原文引用。** 数据库层面有约束：没有引用的题升不到 VERIFIED，也就进不了任何卷子。这是为了保证每道题都能说清"它考的那句话在原文哪一页"。

**凑不够就说凑不够。** 组卷时如果题库里题不够，它会告诉你缺几道、缺哪个知识点，**不会拿不合格的题凑数**。看到"缺口"是正常现象，去补题就行。

## 7. 底部 AI 对话栏

在画布最下面那个输入框，你说人话，它**直接动手改画布**：

```
把课件做成知识卡并出题
```

它不再是"给你一份建议让你点应用"，而是拿一套工具自己去做：查画布、读节点产出、
建节点、连线、改标题和提示词。改完画面立刻变，回复里会列出改了哪几处（绿色 ✓）。

### 它用的是你自己的模型

在「模型供应商」里配好的模型（DeepSeek / 通义 / Kimi / 自建 OpenAI 兼容端点都行）。
没有可用的密钥或模型调用失败时，它会**直说失败原因**，不会用预设话术糊弄你。

### 它看得到画布上的全部内容

底部 AI 拿到的上下文是**每个节点的产出内容 + 最近几轮对话 + 连线关系**，
不是只有标题。所以可以直接问：

```
上确界的定义是什么？引用卡片里的原话
这些概念里哪个最难，为什么？
洛必达法则和画布里的内容有什么关系？
```

- 画布里的问题：它按节点内容回答，并点名出自哪个节点
- 画布外的问题（比如别的章节、别的方法）：它用通用知识正常回答，
  并说明"这部分不在画布内容里"，不会拒答
- 内容太长被截断时，它会自己调工具读全文

对话记录上会标出 **"你的模型（deepseek-flash）"** 这样的字样 ——
那是厂商响应里返回的真实模型标识，证明用的是你自己配的密钥。

### 它能做和不能做的

| 能做 | 不能做 |
|---|---|
| 查看画布、读节点产出 | 执行节点（运行只能你点 ▶） |
| 建 / 改 / 删节点 | 上传文件、访问网络、跑命令 |
| 建 / 删连线 | 改别的画布上的东西 |

删除类操作只在你说"删掉"时才做。

### 一次会话可以连续改

```
你：把课件做成知识卡并出题      → 铺主链 + 出题支线
你：再加一条解题支线            → 只补缺的节点和连线
你：把抽取节点的提示词改严格点   → 只改那个节点的 params.prompt
```

画布上已经有的节点不会重复建，缺的连线会补上。

**对话记录会留在面板里**（展开左侧 ▸ 或数字），点「清空」才消失。

### 也可以直接问节点里的内容

问「知识卡节点现在有多少张卡？」，它会先读那个节点的产物再回答，
读不到就说"这个节点的产出里没有"，不会编。

### 每个节点自己也是一个会话

节点右上角有个 💬，点开就是这个节点的对话面板：

```
· 这条定义的关键在哪？
· 这几步之间有没有跳跃？
· 帮我把这段整理成卡片上的一句话
```

它**只带着这一个节点的产出**当上下文，所以回答贴着这份内容，不会是泛泛而谈。
对话记录按节点分别保存，刷新还在，关掉窗口就清空。

### 它能听懂什么

| 你说 | 它做什么 |
| --- | --- |
| 课件 / 文件 / 上传 / 幻灯 / pdf / ppt | 加课件节点 |
| 切片 / 分段 / 切块 | 加切片节点 |
| 抽取 / 概念 / 知识点 / 提炼 | 加概念节点 |
| 知识卡 / 卡片 / 建卡 | 加知识卡节点 |
| 先修 / 前置 / 依赖 / 顺序 | 加先修节点 |
| 复习 / 记忆 / 背诵 / 到期 | 加复习节点 |
| 题型 / 考点 / 识别 | 加题型识别节点 |
| 解法 / 方法 / 套路 | 加解法抽取节点 |
| 分步 / 讲解 / 演示 | 加分步解法节点 |
| 错因 / 为什么错 / 诊断 | 加错因归因节点 |
| 出题 / 题目 / 练习 | 加出题节点 |
| 整条链 / 全流程 / 从头 / 完整 | 一次性给出标准知识链 |
| 溯源 / 引文 / 出处 / 严格 | 顺带把「严格溯源」绑到概念节点上 |

### 三条使用要点

1. **它只补缺的**。画布上已经有的节点不会重复建。
2. **它绝不自动执行**。节点以 `DRAFT` 状态落地，要你自己点运行。这样做是因为一次批量执行会真的花钱。
3. **没配模型密钥也能用**。上面这张表是靠关键词匹配的，不需要联网也不需要密钥 —— 新建画布的第一步不该卡在"我还没填 key"上。

配了密钥之后，超出关键词范围的复杂请求会转给模型理解；没配就只走关键词。

## 8. 知识网络：一概念一卡 / 深入理解 / 导出讲义

### 知识卡按知识点拆成多个节点

概念抽取跑完后，底部 AI 说一句「把概念拆成知识卡」，或者调 `POST /v1/nodes/<抽取节点>/split-cards`，
它会为**每个概念建一个独立的 CARD 节点**（一个概念一张卡），自动连好 概念 → 知识卡 的线，
并排成网格。

为什么不是一个节点塞 15 张卡：拆开之后每个概念可以单独对话、单独被下游引用，
整张图才会长成思维导图；塞在一起时下游只能拿到"一堆卡"的摘要。

拆出来的卡都是草稿，点 ▶ 各自运行（每张卡只产出自己那一张）。
已经拆过的概念不会重复建。

### 连线 = 把上游节点的对话总结交给下游

每个节点自己就是一个会话（节点上的 💬）。一条连线传下去的不只是产物摘要，
还有**上游节点最近几轮对话**：

```
知识卡节点：你问了「为什么 ε 要取任意正数？」→ 助手答了
        ↓  连线
深入理解节点：运行时会看到这段问答，观点可以直接引用它
```

对话现在**存在数据库里**（不再只存在浏览器），换台机器、刷新页面都还在；
对话变了，下游节点的缓存会自动失效，重跑时读到新内容。

### 一键整理

画布左上角有个「▦ 整理」按钮：按依赖方向把节点排成左→右（上游在左、下游在右），
同层节点保持你原来的上下顺序。

它**只改位置**：不建不删、不连线、不执行，也不会让任何节点失效——随时可以点。
底部 AI 也认得这个动作（说「帮我整理一下」就行）。

### 深入理解（DEEPEN）

只能连**知识卡**和**题目**，别的类型连不上。
运行后给出一组「核心观点」，每条都注明依据的是哪张卡/哪道题；材料不够时会明说缺什么。

### 导出讲义（LECTURE）

可以连**任意多个节点**（知识卡、题目、抽取结果、深入理解都行）。
运行后把它们的产出与对话归纳成一份讲义：标题、章节大纲、正文（Markdown）。

点这个节点上的「导出 PDF」，选保存位置，就会得到 A4 讲义。
PDF 由应用自带的 Chromium 打印，中文排版不需要额外字体。

## 9. 把一组节点打包成一个"上下文"

当一条链已经稳定，你想让别的节点也参考它，不用重复连线：

1. 框选或按住 Shift 点选 **至少 2 个节点**
2. 在其中一个上**右键** → 「打包这 N 个节点为上下文」
3. 起个名字

之后其它节点可以引用这个组作为上下文 —— 组里的节点会进入执行时的输入，和直接连线效果一样，但画布上干净得多。

**组的成员节点被删掉时组不会跟着消失**（组只是"这几个一起看"，可能还有别的成员）。组本身在画布上是独立的一块，可以拖动位置。

## 10. 复习：按遗忘曲线安排

点顶栏 **今日到期** 进入复习。

每次看完一张卡，给它打分：

| 按钮 | 什么时候点 |
| --- | --- |
| **忘了** | 完全想不起来 |
| **勉强** | 想起来了但很吃力 |
| **记得** | 正常回忆 |
| **太简单** | 一看就会 |

### 为什么只有四个按钮

这四个分数会喂给 FSRS 模型，算出**下一次该在什么时候问你**。答"忘了"它会把间隔压得很短；答"太简单"会拉长到几十天。

所以同一个"记得"，对不同的卡、不同的历史，下次时间是不一样的 —— 这不是随机，是它算出来的。

### 两条实用建议

- **如实打。** 觉得"差不多记得"就点"勉强"别点"记得"，虚报会让下次间隔变长，然后你就真忘了。
- **同一天不要反复刷同一张卡。** 系统对同一天内的重复评分做了限制，不会因为你多点几次"记得"就把间隔刷到很长。

## 11. 题库与组卷

点 **题库**。默认显示最近一张画布的题。

每道题显示：题型、状态、难度、被作答过几次、考的是哪些概念。

### 状态

| 状态 | 含义 | 能进卷子吗 |
| --- | --- | --- |
| `PENDING` | 刚出出来，还没质检 | 能（但建议先质检） |
| `VERIFIED` | 过了三检或人工确认 | 能 |
| `REJECTED` | 质检没过 | **不能**，灰掉且不可选 |

### 组卷

1. 勾选你要的题
2. 点 **「用选中的题组卷」**
3. 卷子生成成功会显示「✓ 已组卷：N 道题，共 M 分」

卷子按你勾选的**顺序**排题 —— 你先勾的排在前面，所以勾选顺序就是你想的题序。

**不能跨画布组卷。** 混两个画布的题会让权限判定失效，接口会直接拒绝。

## 12. 错题看板

点 **错题看板**。最近 30 天的统计。

上面四个数字：作了多少题、答错多少、标了错因多少、还有多少错题没分析。

下面是错因条形图：

| 错因 | 意思 | 该怎么办 |
| --- | --- | --- |
| 概念没懂 | 用到的基础概念本身没掌握 | 回去看那张知识卡 |
| 用错方法 | 选了个不适用这类题的方法 | 看「解法抽取」节点的方法适用范围 |
| 漏条件 | 没看见或没用到题给的条件 | 练习读题时圈条件 |
| 算错 | 思路对，运算出错 | 放慢计算，做完验算 |
| 看错题 | 把条件或问题理解错了 | 读两遍再动笔 |
| 没检查 | 答案不完整或没验证就交 | 养成最后回看一遍 |

### 错因是怎么来的

**不是模型事后猜的**，是**每个错误选项本身就绑定了一种错因**。你选了 B，而 B 对应"漏条件"，系统就知道你漏了条件。

所以如果看板上"有作答但没有标记错因"，说明那道题的选项没有绑定错因 —— 去重新生成一次干扰项，或者检查题目是怎么来的。

## 13. 配置模型供应商

点 **模型供应商**。

### 添加密钥

1. 找到你要用的供应商（DeepSeek、OpenAI、Anthropic 等）
2. 粘贴 API 密钥
3. 点 **保存**

保存成功后会自动拉取这家供应商的**可用模型列表**。

### 密钥是怎么存的

- 用 AES-256-GCM 加密后存进本地数据库
- 主密钥在 `byok-key.json`，第一次启动时自动生成
- **界面上永远只能看到末四位**（`sk-…a1b2`），完整密钥存进去之后再也拿不回来 —— 这是刻意的

如果哪天 `byok-key.json` 丢了，已存的密钥就解不开了，需要重新填。所以备份数据目录时**连这个文件一起备份**。

### 选模型

模型列表拉下来后以标签形式展示。**点标签本身什么都不会发生** —— 它只是显示。

每个标签右边有个小按钮：

- **停用** —— 这个模型不再出现在下面的任务下拉里（但**仍然显示在这里**，灰掉）
- **启用** —— 恢复可选
- 供应商旁边还有 **全部启用**，一次把停用的都恢复

> **DeepSeek 现在只有两个模型**：`deepseek-flash` 和 `deepseek-v4-pro`。拉到两个是正常的。
> 早先版本里出现过 `deepseek-chat` / `deepseek-reasoner`，那是过时的名字，已从种子数据里移除。

**停用的模型也会出现在下拉里**，标着「（已停用）」。选了它不会静默失败 —— 会红字提示去上面启用。
这是刻意的：看不见的选项等于不存在，而"点不动"最让人困惑。

### 「各任务用哪个模型」

页面下方是**按任务类型指定模型**的地方，比如：

| 任务 | 建议 |
| --- | --- |
| 抽取、切片 | 用便宜的模型就够 |
| 出题、变式、质检 | 用推理强一点的 |
| 判分（主观题） | 用强的，判错代价高 |
| **底部对话** | 它要读画布内容、还要调工具改画布，建议用推理强的；想更快更便宜可以换成 flash |

不选就走默认路由（软件内置的一张表）。下拉里只出现**已保存密钥 + 已启用**的模型 —— 少了密钥的供应商不会出现在这里，因为选了也跑不起来。

### 自定义端点

如果你用的是中转站或本地部署的模型：

点「添加自定义供应商」，填：
- 名称
- Base URL（例如 `https://gw.example.com/v1`）
- 模型名（可稍后再补）
- 密钥（本地端点没有密钥可以留空）

## 15. 常见问题

### 打开软件是白屏 / 一直转圈

先看软件自己的日志窗口（启动时那个黑框）。常见原因：

- **数据库没起来** —— 日志里会有 `内置库已启动` 或报错。如果提示共享内存残留，关掉软件等 5 秒再开，它会自己清理。
- **端口被占** —— 软件每次启动随机选端口，一般不会撞。真撞了重启即可。

### 运行节点报"没有通过复核的概念"

出题、先修、复习都需要**已确认**的概念。去 **知识卡** 节点的产物里把卡逐张确认（ACCEPT）之后再跑。

### 运行节点报"缺少 params.xxx"

有些节点（题型识别、解法抽取、分步解法、变式、干扰项、质量闸门）需要你**把题目/例题原文填进节点参数**。它们不是自动读上游的 —— 因为是针对某一道具体题在处理。

在节点上右键 → 重命名 旁边的区域可以编辑参数；或者先把上游节点跑出产物再连过来。

### 出题一直失败

按顺序检查：

1. **密钥配了吗？** 模型供应商页面有没有显示 `✓ 密钥已保存 sk-…xxxx`
2. **有已确认的概念吗？** 概念卡状态必须是 VERIFIED
3. **概念有原文引用吗？** 没有引用的概念，出的题挂不上引用，会被数据库挡在 VERIFIED 之外
4. **额度够吗？** 供应商那边余额不足会直接报错

### 出的题进不了卷子

题目状态是 `PENDING` 才能进（`REJECTED` 不行）。如果你希望只有质检过的题进卷子，先跑 **质量闸门**。

### 画布上的节点变灰了（STALE）

说明它上游的某个节点重跑过了，产物可能对不上。**它不会自动重跑** —— 你看一眼，觉得需要就手动点 ▶。

### DeepSeek 只拉到 2 个模型，下面又选不了

DeepSeek 官方就两个模型（`deepseek-chat`、`deepseek-reasoner`），拉到两个是对的。

选不了是因为模型被**停用**了：标签会变灰。点标签右边的「启用」，或者用「全部启用」，下面的任务下拉就会有了。

下拉里还要求这个供应商**已保存密钥**。没存密钥的供应商不出现 —— 因为选了也没有能用的凭据。

### 我改了提示词，但结果没变

两件事要一起做：

1. 悬停节点 → 写提示词 → **保存参数**
2. **点 ▶ 重新运行**

保存只写库。另外改提示词会让这个节点的指纹变化，所以**不会命中旧缓存**，重跑一定会真的调模型。

### 上传后提示「没有文字层，是扫描件」

说明这份 PDF 整页都是图片。回到上传，**勾选「扫描件（OCR）」**重新上传一次。

如果 OCR 之后仍提示「文字层不可用」，说明识别质量太差（糊、歪、公式多）。这种情况换电子版课件最省事 —— 拿乱码当原文，下游会生成"看起来像概念、引用一段乱码"的假卡。

### 上传 .ppt 提示不是旧版格式

多半是把 `.pptx` 改名成了 `.ppt`。改回 `.pptx` 再传即可，两种格式的解析方式完全不同。

### 换电脑后模型密钥全部失效

`byok-key.json` 没一起拷过去。重新填一遍密钥即可（旧的密文已经解不开了）。

### AI 对话栏没反应

底部对话栏**必须**有可用的模型密钥（「模型供应商」页面）。
没有密钥时它不会假装懂 —— 会直接把失败原因写在对话里（例如"没有可用的 deepseek 凭据"）。

如果报「返回的内容不是合法 JSON」或「输出被截断」，多半是模型的输出额度不够，
升级到 0.21.1 及以上版本会自动加倍重试。

### 软件能装到别的电脑吗

能。安装包自带 Node 运行时、PostgreSQL、向量扩展，目标电脑**不需要装任何东西**，也不需要 Docker，不需要管理员权限。

要求：**64 位 Windows**。32 位机器装不了。

## 附：一条完整的链长什么样

```
课件(SOURCE)
   │  抽出原文
   ├──► 切片(CHUNK) ──► 概念(EXTRACT) ──► 知识卡(CARD) ──► 复习(REVIEW)
   │                                          │
   │                                          ├──► 先修(PREREQ)
   │                                          │
   │                                          └──► 出题(QUIZ) ──► 质量闸门(CHECK) ──► 组卷(PAPER)
   │
   └──► 题型识别(PROBE) ──► 解法抽取(METHOD) ──► 分步解法(SOLVE)
                                                    │
                                          你的作答 ──► 错因归因(DIAGNOSE)
```

左边这半边是**建库**（把课件变成可复习、可出题的知识），右边这半边是**解题**（针对具体题目提炼方法、分析错因）。两边可以独立用。
