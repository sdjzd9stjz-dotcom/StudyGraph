## 7. 已裁决的分层校验（方案 A，用户拍板）

**背景**：27 条候选只有 7 条过"逐字"校验（根因是 `definition.trim() !== quote`，要求抽出的定义与引文逐字节相同）。22 字/页的 PPT 上必然产出不了这种"定义=引文"的句子。

**裁决：把一条断言拆成两条。**

| 判定 | 问什么 | 能不能机械验 |
| --- | --- | --- |
| **A1** 引文在不在原文 | `quote` 是否逐字出现在 span 原文 | ✅ 能，**一秒都不能松** |
| **A2** 定义是不是合理转述 | `definition` 是否由 `quote` 支撑 | ⚠️ 只能近似 |

**三档结论：**

| 档 | 条件 | 结果 |
| --- | --- | --- |
| T1 | A1 过 + 定义=引文 + 名称在定义 + residual 含谓词 | `VERIFIED` |
| T2 | A1 过 + 名称在 + residual 含谓词 + bigram Jaccard ≥ 阈值 | `PENDING_REVIEW` |
| T3 | 其余（含 A1 失败、纯标题） | `UNVERIFIED`，不产卡 |

**数量口径（两条都报，缺一不可）：**

```
VERIFIED 单独           ≥ 10（目标 15）
VERIFIED + PENDING_REVIEW ≥ 10（目标 15）
```

**红线：宁可交 10 张真卡，不要 15 张假卡。** `PENDING_REVIEW` 不是免检通道。

### 9.1 一句话

学生填自己的 key、选个模型就能用；预置 10+ 厂商端点，只填 key 即可；也能自定义 OpenAI 兼容端点。对标 Cherry Studio 的供应商管理。**前端仍禁止直连厂商 API。**

### 9.2 性质：规格偏离备案（SG-SUP-013 待编号）

| 项 | 原来 | 现在 |
| --- | --- | --- |
| 凭据归属 | 系统单一密钥 | **每个用户自己的 key** |

> 「自建 Gateway」这条锁定决策**不变**——仍是我们的网关，只是凭据来源从一个变成多个。

### 9.3 监理要盯的四个点（规格里都写死了，这里是我的检查清单）

1. **凭据只进不出**——任何响应只有 `last4`。要专门验"响应体里有没有明文"，不能只看"实现了加密"
2. **429 ≠ INVALID**——最容易被做成"任何错误都判 key 失效"，一次网络抖动能把好 key 判死
3. **解析结果必须进指纹**——`credentialId` / `modelId` / `baseUrl` 都要算。否则就是"A 项缓存"错误的第四次重演
4. **能力不匹配拦在保存时**——学生用不支持 JSON 的模型跑 `extract`，整条链路产物作废且他不知道为什么

### 9.4 与 M2 的关系

**BYOK 后端排进 M2，但它不是 M2 关闭的前提。** 当前 M2 已有 13 项欠账（§5），再压一个多供应商体系进去会把交付质量拉薄。

## 12. 高频陷阱（专属本项目，已踩过）

| 陷阱 | 识别方式 |
| --- | --- |
| **用身份代替内容做判定** | span 缓存用 `(id,page,区间)`、source 指纹用 `path`、产物丢 `quote` —— **三次同一个错误** |
| **只问"有没有"不问"是不是人话"** | 劣质 OCR 的乱码能通过 span 校验 |
| **静默截断** | `chunk` 吞字符、CTE `depth < 64`、视图返回空数组 |
| **护栏自身静默降级** | `check-drift.mjs` 连不上库却报"无漂移"；`check-guards-sync.mjs` 只看部分迁移 |
| **缓存把校验函数变成恒真函数** | 判定函数的输入没全部进缓存键 |
| **前端拦、后端不拦** | curl 绕开 UI 直测 |
| **单层 stale** | 造 A→B→C，改 A 查 C |
| **判据被悄悄弱化** | 巡检从"完整 T1"变成"只看 A1"，测试全绿 |
| **把结果当依据** | 存了 `verdict` 不存 `quote`，事后无法证明它对 |
| **单一错误串两处** | 把 `indexOf` 改成 `search` 后偏移错位（本项目的真实案例） |
