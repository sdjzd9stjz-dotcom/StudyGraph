## 6. 自主决策项

- 复核接口沿用项目 `/v1` 前缀，复核人取已鉴权用户，并拒绝冒名。接口层正负例通过。指令示例使用 `/api`，调用文档应给出实际路径。
- 请求别名与响应 model 分列符合计量语义。`deepseek-chat → deepseek-flash` 是已记录的历史观测，`deepseek-reasoner` 尚无实测映射。[架构说明](../architecture.md)
- EXTRACT 提示词仍要求 definition 和 quote 填同一句原文（`extract.ts:26`）。遵照提示的模型不会主动产出转述。这会影响 T2 样本来源，需在真实校准报告里说明；本轮没有据此推算 T2 数量。
- 独立验收采用 PGlite 16.4 兼容引擎执行原始 SQL，并用 Fastify 注入测试 HTTP 行为。这些替代环境的适用范围已列在 §2、§3。未把改业务代码列为本次交付。
